# 任务清单

## B. 核心治理任务

### B1 代码质量与代码规范

> 规范不再提供给开发使用，与开发相关的全部将规范包含在技能里面封装

- java 开发规范，以及AI 技能化
- python 语言开发规范，以及AI 技能化
- React 语言开发规范，以及AI 技能化
- 数据库设计规范，以及AI 技能化
- 提交规范，以及AI 技能化
- CI/CD 质量规范，以及AI 技能化
- 代码评审清单，以及AI 技能化
- 漏洞扫描，以及AI 技能化

### B2 开发框架

> 通用框架是开发依赖基于是作为开发规范的执行的基础

- Java 后端通用基础开发组件，独立工程，独立技能
- Python 后端通用基础开发组件，独立工程，独立技能
- Web 管理端通用基础开发组件，独立工程，独立技能
- 技术栈：通用，简单，快速，易用
- 中间件：控制中间件的选型，成熟，稳定，易于使用为目标

### B3 系统架构

> 基于业务模式划分领域后，拆分服务，明确扩展和服务边界，以及各个中断的访问边界

- 服务领域划分和服务粒度
- 服务调用与数据控制
- c 端服务结构
- b 端服务结构
- 运营端服务结构
- 多租户服务结构

### B4 数据架构

> 重点在数据表结构，面向 B 端业务的租户隔离，数据访问的有效性

- 数据表领域划分
- 数据字典
- 多租户数据隔离
- AI 会话数据存储
- 数据归档与数据清理
- 运营分析数据体系

### B5 服务治理

> 主要是基于云服务平台，明确使用接入要求，重点在监控告警

- 服务注册发现
- 服务配置
- 异常告警
- 日志采集与监控
- 服务指标采集与监控
- 发布与版本管理、灰度发布

### B6 系统安全

> 结合人员权限的管理，避免风险发生

- 熔断限流，并发控制，对外网关
- 认证鉴权：客户端，服务端，管理端
- 敏感数据加密
- 密钥管理
- 基础权限管理
- 个人信息保护合规（海外）

### B7 Agent 架构

> 主要在 Agent 运行框架和数据使用

- AI Agent 运行框架与开发扩展
- AI 模型与 Prompt 管理
- 用户记忆与存储
- 知识数据结构与存储
- 计费运营

### B8 部署运维

> 重点在扩容和高可用保证

- 环境管理（开发/测试/生产）
- 备份与恢复
- 灾备方案
- 容量规划与扩容
